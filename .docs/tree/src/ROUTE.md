# Source Route

This route describes only the contents of the mirrored `src/` folder.

| Entry | Description |
|---|---|
| `audio/` | Playback command type and worker; see `audio/ROUTE.md`. |
| `api/` | HTTP API composition and sound feature; see `api/ROUTE.md`. |
| `catalog/` | Sound metadata and persistence; see `catalog/ROUTE.md`. |
| `config/` | Runtime settings loaded from environment variables; see `config/ROUTE.md`. |
| `main.md` | Description of the real `src/main.rs`. |
| `app.md` | Description of the real `src/app.rs`. |
