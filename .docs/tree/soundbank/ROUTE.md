# Soundbank Route

This route describes only the contents of the mirrored `soundbank/` folder used by the local-development `./soundbank` fallback or `PERUN_DATA_DIR=./soundbank` override.

| Entry | Description |
|---|---|
| `digest.md` | Description of the persisted catalog manifest. |
| `sounds/` | Uploaded audio storage; see `sounds/ROUTE.md`. |
